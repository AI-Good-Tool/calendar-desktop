# 云小历

<img src="public/logo.png" alt="云小历应用图标" width="96" />

轻量桌面日历，把日历、日程、天气和多时区时钟放在一起。支持 macOS 与 Windows，提供中英文界面。

[下载安装包](https://github.com/AI-Good-Tool/calendar-desktop/releases/latest) · [问题反馈](https://github.com/AI-Good-Tool/calendar-desktop/issues)

## 界面预览

### 日历主界面

![云小历主界面：左侧月历展示公历、农历、节气和休假调休标记，右侧展示日程入口、农历宜忌、天气与世界时钟，底部提供常用工具入口](docs/images/calendar-overview.png)

打开云小历即可查看当月日期与假期安排，右侧集中展示每日信息，底部可快速打开日期工具。

| 界面区域 | 功能与用法 |
| --- | --- |
| 左侧月历 | 同时显示公历、农历、传统节日与二十四节气；通过“休”“班”标记区分放假与调休工作日。点击日期可查看对应信息。 |
| 月历顶部 | 使用左右箭头切换月份，点击“今日”回到当天；通过“假期安排”跳转查看节假日，点击蓝色“＋”创建日程。 |
| 右侧日程入口 | 查看当前周数与年内天数，点击“创建日程”添加待办、事件、生日、纪念日或倒数日。 |
| 右侧农历卡片 | 查看所选日期的农历、干支与宜忌信息。 |
| 右侧天气卡片 | 查看所选城市的天气、温度与风力，打开未来预报；通过设置图标切换城市。 |
| 右侧世界时钟 | 对照不同时区的日期与时间。截图下方仅展示了卡片的一部分，向下滚动可查看完整内容。 |
| 底部工具栏 | 快速打开公农历转换、节日大全和日期计算，点击“全部”浏览更多工具。 |

顶部还提供“订阅”和“工具”入口，可按需选择右侧信息卡片或进入工具页面。macOS 用户也可以在系统状态栏直接查看时间，效果如下。

### macOS 多时区状态栏

![云小历 macOS 双时区状态栏：左侧显示主时区的日期、星期与时间，右侧显示洛杉矶的日期与时间](docs/images/menu-bar-timezones.png)

上图展示主时区与洛杉矶时区同时显示的效果。两个时区各自显示对应日期，跨日时也能直接看出区别，适合出差、跨国协作或关注异地时间。

## 多时区与自定义时区

### 同时显示两个时区

macOS 状态栏支持同时显示 **主时区和第二时区**。第二时钟独立设置时区和显示格式，并自动加上城市名称；主状态栏还可显示天气。

1. 打开右上角用户图标，进入 **系统设置 → 常规设置**。
2. 在 **系统状态栏显示** 中开启 **显示时间与天气**。
3. 在 **第二时区时间（菜单2）** 中开启 **显示第二时区时间**。
4. 选择第二时区，例如 **洛杉矶（America/Los_Angeles）**，再选择或输入显示格式。

> 首次开启第二时区时，如果应用提示需要重启，点击“立即重启”，或稍后手动重启应用即可生效。第二状态栏只显示日期／时间，不显示天气。双时区状态栏功能适用于 macOS。

### 跟随系统，或使用固定时区

在 **系统设置 → 常规设置 → 时区** 中：

- **开启“跟随系统时区”**：主时区跟随系统时区变化，适合出差时使用。
- **关闭“跟随系统时区”**：在“使用时区”下拉框中搜索并选择固定时区，例如北京、纽约或洛杉矶。主时钟会使用选定时区，第二时钟仍按自己的设置显示。

可选时区包括：

| 显示城市 | 时区标识 |
| --- | --- |
| 北京 | `Asia/Shanghai` |
| 纽约 | `America/New_York` |
| 洛杉矶 | `America/Los_Angeles` |
| 伦敦 | `Europe/London` |
| 东京 | `Asia/Tokyo` |

时钟按所选时区规则计算时间，适用地区的夏令时也会随之调整。

### 自定义状态栏格式

两个时钟都支持选择预设或输入自定义格式，例如：

| 格式 | 显示内容 |
| --- | --- |
| `HH:mm:ss` | 时、分、秒 |
| `M月D日 ddd HH:mm:ss` | 月、日、星期与时间 |
| `M月D日 ddd` | 月、日与星期 |

第二时钟会自动添加城市前缀，无需在格式中重复输入城市。主状态栏另支持 `{city}`、`{temp}`、`{weather}` 天气占位符。

## 📝 配置说明

### 天气API配置

进入 **系统设置 → API 配置 → 天气数据源**，选择需要的服务。默认 Open-Meteo 无需 Key；选择标有 🔑 的数据源后，在设置页面填写对应服务的 API Key 即可。

### 城市配置

点击右侧天气卡片的设置图标，搜索并选择天气城市。天气城市与时钟的时区分别设置；修改天气城市不会改变时钟时区。

## 🍎 MacOS 运行说明

如果您在 macOS 上运行应用时遇到 **“无法打开，因为无法验证开发者”** 或 **“应用已损坏”** 的提示，这是因为应用未进行 Apple 开发者签名（$99/年）。

请在终端中执行以下命令来移除隔离标记：

```bash
sudo xattr -r -d com.apple.quarantine /Applications/云小历.app
```

> [!IMPORTANT]
> 此命令仅应用于您信任的应用。执行后即可正常打开应用。
